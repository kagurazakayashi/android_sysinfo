# システム情報定数

**言語**: [English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | 日本語

システム情報定数は、デバイスの `android.os` パッケージ内のすべてのクラスを閲覧できる Android アプリです。実行時に各公開 static フィールドの名前・型・**現在の値**を読み取り、ネストしたクラスを何階層でも掘り下げて閲覧できます。

このプロジェクトは、システムの中に実際に何が格納されているかを理解するためのものです。Android のバージョンや端末の型番から、バッテリー・ストレージ・電源・メッセージなどのシステム定数までを確認できます。

## 紹介

`android.os` は Android で最も重要なパッケージのひとつで、`Build`（端末情報）、`BatteryManager`（バッテリー）、`PowerManager`（電源）、`Process`（プロセス）、`Environment`（ストレージ環境）、`StatFs`（ファイルシステム状態）などのシステムレベルのクラスが含まれています。

このアプリは `android.os` 配下のすべてのトップレベルクラス（SDK 37 で 120 個）を一覧表示し、各クラスについて次の情報を表示します：

- 型の種類（クラス / インターフェース / 列挙型 / アノテーション）、修飾子、所属パッケージ、親クラス、実装しているインターフェース
- 各公開 static フィールドと、**実機で読み取った現在の値**
- ネストしたクラス / インターフェース。タップするとさらに掘り下げられます

各項目には、現在の言語（日本語・簡体字中国語・繁体字中国語・英語）の説明文と、意味を表すアイコンが付きます。

## 機能

- `android.os` パッケージの全 120 個のトップレベルクラスを閲覧
- 各公開 static フィールドのリアルタイムの現在値を表示
- ネストしたクラスをタップしてどこまでも掘り下げ可能
- 各項目に 4 言語の説明とアイコンを表示
- お気に入り：任意のフィールドをスター登録し、ツールバーからいつでも開ける
- グローバルフィルタースイッチ：static フィールドもネストクラスも持たない空の項目を非表示
- フィールドをタップすると、コピーする内容を選択できる（元の名前 / 翻訳名 / 値 / 完全な項目）
- ツールバーの「すべてコピー」ボタン
- 4 つの UI 言語（日本語・簡体字中国語・繁体字中国語・英語）、アプリ内でワンタップ切り替え、デフォルトはシステムに追従
- ダークモード対応（システムに追従）
- Android 12+ のダイナミックカラー対応（壁紙テーマに追従）

## 動作要件

- Android 8.0（API 26）以上

## インストール方法

### 方法 1：APK を直接インストール（最も簡単）

1. APK ファイルを入手します：`app/build/outputs/apk/debug/app-debug.apk`（または作者にリリース版 APK を依頼）。
2. APK ファイルをスマートフォンに転送します（USB ケーブル、ファイルマネージャー、チャットアプリなど）。
3. スマートフォンで APK ファイルをタップしてインストーラーを開きます。
4. 「不明なアプリのインストール」の許可を求められたら、許可して続行します。
5. インストール完了後、アプリを開きます。

### 方法 2：ADB でパソコンからインストール

1. スマートフォンで**開発者向けオプション**を有効にします：
   - 「設定」を開き、「端末情報」をタップ。
   - 「ビルド番号」を 7 回連続タップし、「開発者になりました」と表示されるまで待ちます。
2. **USB デバッグ**を有効にします：
   - 設定 > システム > 開発者向けオプション >「USB デバッグ」をオン。
3. USB ケーブルでスマートフォンをパソコンに接続し、スマートフォンでデバッグの許可を承認します。
4. パソコンで次のコマンドを実行します：

   ```
   adb install app/build/outputs/apk/debug/app-debug.apk
   ```

5. アプリがアプリ一覧に表示されます。

## 使い方

### ホーム画面（クラス一覧）

- ホーム画面には `android.os` のすべてのトップレベルクラスが、アイコンと翻訳付きの説明とともに表示されます。
- **クラスをタップ**すると詳細画面が開きます。
- サブタイトルに「表示中 / 合計」が表示されます（例：「120 / 120 クラス」）。
- 上部の**スイッチ**で、static フィールドもネストクラスも持たない項目を非表示にできます。このスイッチはアプリのすべての階層で有効です。

### 詳細画面（クラスの内容）

- 型情報（種類、修飾子、パッケージ、親クラス、インターフェース）を表示します。
- **static フィールド**が現在値とともに一覧表示されます。
  - **フィールドをタップ**するとメニューが開き、コピーする内容（元の名前 / 翻訳名 / 値 / 完全な項目）を選択できます。同じメニューからお気に入り登録 / 解除もできます。
- フィールドの下に**ネストしたクラス / インターフェース**が表示されます。
  - **ネストしたクラスをタップ**すると、その詳細画面が開きます。何階層でも掘り下げられます。

### お気に入り画面

- ホームのツールバーのスター型ボタンで開きます。
- お気に入り登録したフィールドと、登録時点の値が表示されます。
- お気に入りをタップすると、コピーまたはお気に入り解除ができます。
- 初回起動時には、メーカー・型番・Android バージョン・API レベルの 4 項目が自動登録されます。

### ホームのツールバーボタン

- 言語ボタン：UI 言語を切り替え（システムに追従 / 简体中文 / 繁體中文 / English / 日本語）。
- スター型ボタン：お気に入りを開く。
- コピーボタン：クラス一覧全体をコピー。

## ビルド方法

### Android Studio を使う場合（初心者向け）

1. [Android Studio](https://developer.android.com/studio) をインストールします。
2. Android Studio を起動し、「Open」を選んでこのプロジェクトフォルダーを選択します。
3. Gradle の同期が完了するまで待ちます（依存関係を自動でダウンロードします。初回は数分かかることがあります）。
4. 実機で実行する場合：スマートフォンを接続（USB デバッグを有効化）し、緑色の「Run」ボタンをクリックしてデバイスを選択します。
5. APK のみをビルドする場合：**Build > Build Bundle(s) / APK(s) > Build APK(s)** をクリックします。APK は `app/build/outputs/apk/debug/app-debug.apk` に生成されます。

### コマンドラインを使う場合

前提条件：

- JDK 17 以上
- Android SDK（`platforms;android-37` と新しい `build-tools` が必要。AGP 9.4.0 は新しいビルドツールを要求）
- リポジトリに Gradle wrapper が含まれているため、Gradle の個別インストールは不要

手順：

1. Gradle に Android SDK の場所を伝えます。環境変数を設定するか：

   ```
   export ANDROID_HOME=/あなたの/android-sdkパス
   ```

   プロジェクトルートに `local.properties` ファイルを作成して書き込んでも構いません：

   ```
   sdk.dir=/あなたの/android-sdkパス
   ```

2. デバッグ用 APK をビルドします：

   ```
   ./gradlew assembleDebug
   ```

   （Windows で Git Bash / PowerShell を使う場合は `.\gradlew.bat assembleDebug` を使用してください。）

3. APK は `app/build/outputs/apk/debug/app-debug.apk` に生成されます。

## プロジェクト構成

```
app/src/main/java/com/example/buildinfo/
├── MainActivity.java          ホーム画面：android.os のクラス一覧
├── ClassDetailActivity.java   詳細画面：クラスのフィールドとネストクラス
├── FavoritesActivity.java     お気に入り画面
├── OsClasses.java             生成済みの android.os クラス一覧（SDK 37）
├── OsInfo.java                フィールドをリフレクションで読むユーティリティ
├── ZhNames.java               クラス / フィールド名の翻訳（4 言語）
├── Icons.java                 クラスとフィールドのアイコン割り当て
├── FavoritesStore.java        お気に入りの永続化（SharedPreferences + JSON）
├── LocaleManager.java         UI 言語の管理
├── Ui.java                    UI ヘルパー（色、角丸背景）
└── App.java                   Application クラス（保存された言語を適用）
```
